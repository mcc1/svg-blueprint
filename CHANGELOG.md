# Changelog

## Unreleased

- Assets (owner decision 2026-11-02, from the Pixel Agents trial): step 1 finds the fonts and art the drawings need, records them in the Assets table of `inventory.md`, and the user decides to download or decline each missing one, told before drawing what declining costs. `build_doc.py` inlines drawings in shadow roots so the table's fonts, declared once on the page, reach every drawing (an SVG in `<img>` loads no outside file); inlines `url()` references; lists declined assets at the top of `index.html`; warns on undecided or missing assets, fonts not in the table, remote URLs and external `<use>`. `guardrails.py` hashes `url()` references too.

## 0.1.0 (2026-11-01)

- Component-first workflow in eight steps: inventory, tokens, states, approval, screens, guardrails, implement, verify.
- Guardrails replace the earlier "whole test set red before implementation" gate (owner decision 2026-11-01): design-derived tests written before a unit is implemented, each failing against a stub, locked with `scripts/guardrails.py`; the agent's own tests follow `/tdd`. A guardrail that looks wrong goes back to the user as a design question.
- EGM stage 9 fixes: `guardrails.py` hashes an SVG together with everything it places, so a reopened component marks its screens changed; `tokens/` and `flow/` are unit folders with spec, log, Interface and Guardrails like components; `inventory.md`; `status: reconfirm` for units changed only through something they use (token value find-and-replace, a placed component); unit order inside a slice; one-time test harness setup; "drawing" defined; step 8 comparison method and uncapturable frames; all commands run from the project root; `build_doc.py` exits 1 on warnings; `check` reads status from front matter only.
- EGM stage 8 fixes: every unit locked at approval (step 4), step 6 adds guardrails; `_build/clean/` committed but not locked; re-confirm instead of full reopen for dependents whose files did not change; tdd mapping shortened; new guardrails in step 8 only when existing ones could not catch a difference; key frames exempt from visual guardrails when not capturable; setup moved to `references/project-setup.md`.
- EGM stage 6-7 fixes: `references/spec-format.md` (contract `spec.md` locked, history `log.md` not) with States, Transitions, Variants, Interface and Guardrails tables; `docs/design-rationale.md`; implementation per approved slice (owner requirement 1); screen `transitions.svg` and `flow.svg`/`flow.md`; `<image>` placement at the referenced size; suffix grammar with size, language, frame, alternative; `guardrails.py unlock`, and `check` fails on approved files that are not locked; `_build/clean/` committed and locked as visual references; anchored `.gitignore` lines; tokens locked at approval.
- EGM stage 5 fixes: `transitions.svg` required when a unit has transitions; approval covers frames, transitions and table together; `_build/clean/` named as the visual reference; screen resolutions limited to layouts that change; one variant-suffix grammar; `review` status assigned in step 4; screens follow the same approval and lock rules.
- Platform-general: `references/platforms.md` covers games, native apps, web and terminal UI (units, states, layout, capture, tests).
- Red-test gate: a unit's whole test set is derived from its approved spec through `/tdd` and must be red on its assertions before implementation; implementation then goes one test at a time to green.
- `references/svg-conventions.md`: canvas, naming, colour and type, annotations, screens.
- `scripts/build_doc.py`: generates `index.html` with states side by side, status badges, screenshots; flattens screens so composed components render through `<img>`; strips component annotations inside screens; writes `_build/clean/` references for visual tests.
- `examples/blueprint`: tokens, a `button` component with transitions and a test list, a `confirm-dialog` screen.
- `AGENTS.md` (with `CLAUDE.md` importing it) for agents changing the skill.
- Review fixes: tests that assert only an absence must also assert the state's visible behaviour so they go red; the test list needs user approval; SVG part ids are exposed as public test hooks; tracer bullet picked first in step 7; tokens approval recorded in `tokens.md`; screenshots under `shots/<kind>/`.
- `build_doc.py`: stripping parses XML (handles self-closing, nested, multi-class, single-quoted groups); placed components lose context groups too; `_build/` rebuilt from scratch; screenshots scale with the drawing; `#` values in front matter survive.
